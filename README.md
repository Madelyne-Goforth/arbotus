# arbotus

Offline, local RAG-based study assistant over Army doctrine, built to run
on a Pi 5 via Ollama. Retrieves relevant doctrine excerpts (tagged with
source doc, section, and pull date) and has a local LLM comment on them
in a senior-mentor persona -- retrieved doctrine and AI commentary are
kept structurally separate in the output.

Status: early build, in progress.
